## リンクの状態（status）と画面表示

| status | 意味 | 画面 |
|---|---|---|
| `ok` | probe で生存確認済み | リンク＋**最終確認日** ＋「確認済み」バッジ |
| `unchecked` | 種まき済み・未検証 | リンク＋「最終確認はこれから」＋**未確認**バッジ |
| `none` | 存在しないと確認済み | 「該当なし」（破線） |
| `dead` | リンク切れ | 非表示＋月次レビュー対象 |

> **公開直後は多くが `unchecked`（未確認）。** VPSで probe.py を1回流すと `ok`（最終確認日つき）へ昇格する。
> 「最終確認日」は自前の死活監視が根拠であり、RILG/uub に載っていた事実とは区別する（設計書 12章）。
