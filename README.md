# TDF47（tdf47.com）

全国 1,741 市区町村の「例規集・議会会議録・広報誌・公式サイト・公式SNS」へのリンクを、虫食いなく網羅した静的サイト。主ターゲットは自治体職員（隣町が何をしているか調べる用途）。隣接自治体への導線が中核。

- ドメイン: **tdf47.com**（未取得。代替候補 `tdf47.jp` / `tdf-47.com` / `47tdf.com`）
- 技術: **SQLite → Jinja2 → 静的HTML → Nginx** の一方向パイプライン（実行時に DB も Python も動かさない）
- 本番: VPS（最小プラン）＋ Nginx（契約先未定）
- 言語: Python **3.12** / Jinja2 / SQLite

## 重要な決定・制約（設計書より）

- 団体コードは **6桁（チェックデジット込み）を主キー**に正規化（5桁で来るソースあり）
- 縦持ちの `link` テーブルが肝。v2.0 で項目が増えても行の追加だけで済む（スキーマ変更不要）
- `status` は 4 値（`ok` / `dead` / `none` / `unchecked`）。`none`（情報が存在しないと確認済み）と「準備中」（`link_kind.phase='v2.0'`）は別物
- **最終確認日（`link.last_checked`）は中核機能。必ず埋める**
- URL は `https://tdf47.com`（www なし・末尾スラッシュあり・小文字 ASCII のみ・日本語/クエリ不使用）
- スラッグは団体名の **かな読み** から機械生成（漢字からは生成しない）。衝突は郡名ローマ字を前置し `reports/slug-collisions.csv` に出力
- 外部クロールは **手元のPCでは行わない**（手元のIPがブロックされると困るため）。VPS から実行する
- 生成対象は `entity.phase='v1.0'` の約 3,700 ページ。v1.5（一部事務組合）は前倒ししない
- 市章・首長名・政令市の行政区独立ページは掲載しない。マンホールカード画像は GKP 照会が済むまで NULL
- クロールのマナー: robots.txt 尊重・1 リクエスト 1 秒以上・User-Agent に連絡先明記

## 作業フェーズ（設計書 14 章）
